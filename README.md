### 📌 Overview
**Kotodur** is a civic-focused urban transit and bus-tracking web application designed to simplify daily public commute navigation in Dhaka. It helps commuters quickly identify bus routes, stoppages, and fare estimates without clutter.

### ✨ Key Features
- **Smart Route & Stoppage Discovery:** Fast origin-to-destination bus lookup across major urban transit corridors.
- **Commuter-First Responsive UI:** Lightweight, mobile-optimized interface engineered for quick lookups while on the move.
- **Type-Safe Architecture:** Built end-to-end with TypeScript and Next.js App Router for predictable data modeling and fast page loads.

### 🛠️ Tech Stack
- **Frontend:** Next.js 15, React, TypeScript, Tailwind CSS
- **Deployment:** Vercel
